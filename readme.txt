Integrate Elementor Pro Form with Google Drive — adds Google Drive as an "Actions After Submit" option with seamless automation.

== Description ==

The Elementor Form + Google Drive Integration Premium Add-on connects your Elementor Pro Form widget directly to Google Drive in real-time.

= Features =

* Add Google Drive as an option in "Actions After Submit" section
* Configure credentials and endpoints easily
* Real-time automated data synchronization on form submit
* Built-in license key activation and auto-updates via GravityExtra

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`
2. Activate the plugin through the 'Plugins' menu in WordPress
3. In any Elementor Pro Form widget, add "Google Drive" to "Actions After Submit"
4. Configure fields and settings
