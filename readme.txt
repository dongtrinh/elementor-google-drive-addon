Connect Elementor Pro Form to Google Drive to automatically upload file attachments and form entries directly to cloud folders.

== Description ==

The Elementor Form + Google Drive Integration Premium Add-on connects your Elementor Pro Form widget directly with Google Drive. Seamlessly upload file attachments (PDFs, images, documents, audio, videos) into designated Google Drive folders without consuming local WordPress web hosting storage.

= Key Features =

* **Zero Server Bloat:** File attachments upload directly to Google Drive, preserving local server disk space and bandwidth.
* **Unlimited File Uploads:** Bypass restrictive PHP hosting file size limits by routing files to Google Drive.
* **Dynamic Subfolders:** Automatically create dedicated subfolders for each submission organized by customer name, email, or date.
* **Custom Properties Mapping:** Map unlimited custom form field inputs to Drive file metadata.
* **Global & Per-Form Settings:** Use a global Google Drive webhook and folder ID or customize per individual form.
* **Integrated Connection Testing:** Verify your Google Drive connection directly inside WordPress admin settings.
* **Automatic Updates:** One-click license activation and updates powered by GravityExtra.
